# titan-game-ksp

Kerbal Space Program adapter over the kRPC 0.5.x mod (D12, Section 7.3). The manifest and
integration installer arrive in M4.T3, the adapter and read-only calculators (`titan_game_ksp/tools.py`)
in M5.T2, `events.yaml` in M5.T4, and the `launch-to-orbit` and `crash` fixtures in M5.T5.
